# Bundled fonts

Unmodified static TrueType Noto Sans Regular, Bold and Italic, and Noto Serif Regular, from `notofonts/noto-fonts`, commit `ffebf8c1ee449e544955a7e813c54f9b73848eac` (retrieved 25 September 2026).

Upstream paths: `hinted/ttf/NotoSans/` and `hinted/ttf/NotoSerif/` at https://github.com/notofonts/noto-fonts . Original upstream licence preserved verbatim in OFL.txt. Release manifest records the hashes of the actual files used. No system font is required.
